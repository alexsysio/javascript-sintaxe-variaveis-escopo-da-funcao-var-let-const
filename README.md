### Escopo da Função
### Dentro de uma função, todas as variáveis declaradas com var, let, const, tem ou possuem Escopo de Função nesse exemplo: 
### function myfunction() {
###   var x = 1;
###   let y = 2;
###   const z = 3;
### }
### //x não pode ser usado aqui
### //y não pode ser usado aqui
### //z não pode ser usado aqui
