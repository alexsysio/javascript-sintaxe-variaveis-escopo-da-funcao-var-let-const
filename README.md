### Escopo da Função
### Dentro de uma função, todas as variáveis declaradas com , ou possuem Escopo de Função: var let const

&nbsp;

### Exemplo

&nbsp;

### function myfunction() {
###   var x = 1;
###   let y = 2;
###   const z = 3;
### }
### //x can NOT be used here
### //y can NOT be used here
### //z can NOT be used here
